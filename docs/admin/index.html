Beauty Case

Игра-расследование: три команды, три клиентки, один настоящий запрос у каждой

Правила игры

1Команда получает код и заходит к своей клиентке с телефона.
2Клиентка не говорит главного сама. Она отвечает только на точные вопросы.
3Нужно раскрыть 4 факта: повод, привычки, ограничения и то, чего клиентка боится.
4Кто первым раскрывает все факты — получает задание и собирает образ офлайн.

Названия команд

Впишите, как называются команды. Клиентка у каждой своя.
